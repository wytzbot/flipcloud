# Flipcloud — Marketplace listing copy

## Application name
Flipcloud

## Short description
Developer-focused cloud setup assistant for inspecting Google Cloud projects, discovering API requirements, and simplifying common setup tasks.

## Detailed description
Flipcloud helps developers move from code to a configured cloud project with less console hopping.

Connect a Google account, inspect accessible projects, review enabled services, search a developer-oriented API catalog, and run a lightweight code requirement scanner that maps common dependencies to likely Google services.

Flipcloud also provides optional GitHub identity through Firebase Authentication and browser alerts through Firebase Cloud Messaging.

### Key features
- Google Cloud project discovery
- Enabled API/service inspection
- Single and batch API enable requests
- Developer API catalog
- Rule-based dependency/code requirement scanner
- Search across tools and pages
- Optional GitHub sign-in
- Optional browser notifications
- Mobile-friendly developer interface
- Clear permission prompts and actionable errors
- Recurring Pro plan: $3.99/₦4,500 monthly or $30/₦40,000 yearly

Flipcloud does not bypass Google Cloud IAM, quotas, organization policies, billing requirements, or service restrictions. Google Cloud usage charges remain the user's responsibility.
