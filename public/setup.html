Setup Guide

Google

Configure a Web OAuth client and the production callback URL. Enable Cloud Resource Manager and Service Usage API. Grant users only the project permissions required for the actions they choose.

Firebase

Enable GitHub in Firebase Authentication and configure the authorized domain. Enable Cloud Messaging for browser alerts.

Flutterwave

Set v4 client credentials, hosted Payment Plan IDs, the production callback URL and webhook secret. Keep all secret values server-side.

Marketplace

Deploy the app over HTTPS, verify the domain, configure the Marketplace SDK Web app integration, and use the production URL as the Universal Navigation URL.
