Support

Start by checking the Setup Guide and the exact error shown by Flipcloud. For Google Cloud failures, confirm the selected project, IAM permissions, API status and billing configuration.

Google session expired

Sign in again. Flipcloud will not silently reuse an invalid authorization session.

API cannot be enabled

The connected account must have permission to enable services on the selected project. Some Google services also require billing to be enabled.

Notifications do not arrive

Browser notification permission must be granted and the device/browser must support FCM Web Push.

Billing

Do not rely on the checkout redirect as proof of payment. Flipcloud verifies payment events server-side.
