Privacy Policy

Flipcloud uses information needed to provide developer cloud setup, authentication, billing and notifications. Google OAuth tokens are used to access the Google Cloud resources you authorize. Flipcloud does not request access to unrelated Google services unless a future feature explicitly requires it.

Billing is processed by Flutterwave. Flipcloud should not receive or store full card numbers or security codes. Browser notification tokens may be stored so enabled alerts can be delivered.

Do not place API secrets, private keys or service-account credentials into code submitted to Flipcloud.

For privacy requests or support, use the support contact published for your deployment.
