WEBSITE

Connect a website without GitHub

Enter a public website and Flipcloud will inspect what can be safely detected without installing anything. For deeper live diagnostics, add the SDK after the scan.

Add Flipcloud SDK

After creating a project, add this lightweight snippet to your site:

<script src="https://cdn.flipcloud.dev/sdk.js" data-flipcloud-project="YOUR_PROJECT_ID" async></script>

The SDK is intended for diagnostics you explicitly enable; it should not collect passwords, payment data or private content.

GUIDE

What Flipcloud can do

Permissions

Each operation explains the permission it needs. You can enable the permission or ignore the action. Ignoring it never blocks unrelated tools.

Costs

Flipcloud's diagnostics and catalog are local/rule-based. It does not proxy paid AI or cloud workloads for you. Enabling a Google service does not make the service free; any applicable usage charges remain on the user's project.

Third-party APIs

GitHub, npm metadata, jsDelivr/unpkg package delivery and other public developer services can be integrated without Flipcloud paying per request when used directly from the user's browser. Paid provider operations should remain in the user's account.
